# 04. Безопасный минимальный режим продукта

## Цель

Выпустить пригодную для раннего использования версию, которая группирует и stage-ит hunks, но не удаляет изменения и не создаёт commits самостоятельно.

## Анализ

Главная пользовательская ценность — именованные changelists и распределение hunks. Наиболее рискованные операции — `Discard` и собственный commit с перестройкой реального index. Их можно временно исключить, сохранив безопасный workflow: выбрать changelist, stage, проверить стандартный Staged Changes и выполнить commit встроенным Git UI.

При этом расширение не должно создавать ложное ощущение изоляции: если index уже содержит другие изменения, стандартный commit включит и их. UI обязан явно показывать pre-existing staged changes и предлагать только безопасные действия.

## Зависимости

- Эпики 01–03.

## План реализации

1. Удалить/feature-gate регистрации, menus и inline buttons для Commit и Discard.
2. Оставить create/rename/delete списка, assignment, diff и stage; удаление списка удаляет только metadata.
3. Перед stage показывать состояние index и предупреждать, если там есть hunks вне выбранного changelist.
4. После stage открывать или фокусировать стандартный SCM Staged Changes для ручной проверки.
5. Добавить команду безопасной отмены только staging выбранного набора без изменения worktree.
6. Обновить README, changelog и onboarding с точным workflow и ограничениями.
7. Собрать локальный pre-release VSIX и выполнить smoke-тест в отдельном репозитории.

## Критерии качества и приёмки

- В Command Palette, tree view и package manifest отсутствуют доступные Commit/Discard действия.
- Ни один доступный пользовательский путь не вызывает `git commit`, не удаляет файл и не применяет patch к worktree.
- Stage меняет только index; байты worktree до/после совпадают во всех тестах.
- Пользователь видит чужие staged changes до продолжения и может отменить операцию.
- После stage стандартный VS Code diff позволяет проверить точный будущий commit.
- Установка VSIX не требует runtime npm dependencies и проходит smoke-тест на поддерживаемых ОС.
